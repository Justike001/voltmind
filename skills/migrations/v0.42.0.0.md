# v0.42.0.0 Migration: Schema-pack CLI floor

The built-in Personal Brain and Company Core schema packs now require VoltMind
CLI version 0.42.0 or newer. Older clients must upgrade before they can safely
load and write against those packs.

1. Upgrade the CLI:

   ```bash
   voltmind upgrade
   ```

2. Apply any pending migrations:

   ```bash
   voltmind apply-migrations --yes
   ```

3. Confirm the installed CLI and active schema pack:

   ```bash
   voltmind --version
   voltmind schema show --json
   voltmind doctor
   ```

Do not bypass the version floor. If the active schema pack still rejects the
CLI after an upgrade, retain local source evidence and resolve the installation
before running client-first semantic writes.
